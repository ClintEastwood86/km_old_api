# KingMovies Backend API

## Обзор проекта
**KingMovies Backend** — это серверное приложение (API) для платформы онлайн-кинотеатра с развитой системой социальной активности и геймификации. Проект построен на **Node.js** с использованием **Express** и **TypeScript**, реализует чистую архитектуру с внедрением зависимостей (Dependency Injection) и строгой типизацией.

Приложение управляет пользователями, фильмами, коллекциями, комментариями, а также включает сложные механики начисления очков, рангов и наград.

## Технологический стек

### Основные технологии
*   **Язык:** [TypeScript](https://www.typescriptlang.org/)
*   **Платформа:** [Node.js](https://nodejs.org/)
*   **Веб-фреймворк:** [Express.js](https://expressjs.com/)
*   **Архитектура:** DI на базе [InversifyJS](https://inversify.io/)
*   **ORM:** [Prisma](https://www.prisma.io/) (работает с PostgreSQL)

### Базы данных
Проект использует **PostgreSQL** и разделен на две логические базы данных (два Prisma клиента):
1.  **Common Database:** Хранит пользователей, комментарии, коллекции, награды, историю активности и настройки.
2.  **Movies Database:** Хранит информацию о фильмах, актерах, жанрах, рейтингах (структура, ориентированная на контент).

### Инфраструктура и Инструменты
*   **Контейнеризация:** Docker
*   **Мониторинг и Логирование:**
    *   [Prometheus](https://prometheus.io/) (метрики)
    *   [Loki](https://grafana.com/oss/loki/) & Promtail (сбор логов)
    *   [Sentry](https://sentry.io/) (отслеживание ошибок)
*   **Планировщик задач:** `node-schedule` (фоновые задачи, очистка, начисление бонусов)
*   **Тестирование:** Jest (Unit и E2E тесты)
*   **Валидация:** `class-validator`, `class-transformer`

## Архитектура
Проект следует модульной слоистой архитектуре, напоминающей NestJS, но реализованной на Express + Inversify:
*   **Controllers (`*.controller.ts`):** Обработка HTTP-запросов и маршрутизация.
*   **Services (`*.service.ts`):** Бизнес-логика приложения.
*   **Repositories (`*.repository.ts`):** Слой доступа к данным (абстракция над Prisma).
*   **Containers (`*.container.ts`):** Настройка DI-контейнеров для каждого модуля.
*   **Entities/DTO:** Описание моделей данных и объектов передачи данных.

## Основные Модули

### 1. Пользователи (`/users`)
*   Регистрация, авторизация (JWT), восстановление пароля.
*   Ролевая модель: `USER`, `MODERATOR`, `ADMIN`.
*   Профили пользователей, аватарки, настройки уведомлений.
*   Блокировка и верификация аккаунтов.

### 2. Фильмы (`/movies`)
*   Каталог фильмов и сериалов.
*   Интеграция с базой данных фильмов (информация о "Кинопоиск/IMDB", актеры, жанры, страны).
*   Поиск, фильтрация, похожие фильмы.
*   WebSocket-контроллер для обновлений в реальном времени.

### 3. Геймификация и Ранги (`/ranks`, `/points`, `/awards`, `/bonus`)
*   **Ранги:** Система уровней пользователей, зависящая от очков.
*   **Очки (Points):** Начисление очков за активность (просмотры, подписки).
*   **Награды (Awards):** Достижения, которые пользователи могут открывать и выбирать для отображения.
*   **Бонусы:** Система множителей опыта (multiplier) и временных бустов.
*   **Лидерборды:** Списки лучших пользователей по годам/активности.

### 4. Социальное взаимодействие
*   **Комментарии (`/comments`):** Древовидные комментарии к фильмам с возможностью лайков/дизлайков.
*   **Коллекции (`/collections`):** Пользовательские подборки фильмов (публичные/приватные), возможность подписки на коллекции.

### 5. Система мониторинга и обслуживания
*   Сбор метрик производительности (middleware).
*   Автоматическая очистка "пустых" и забаненных пользователей.
*   Ежедневное начисление очков подписчикам.
*   Интеграция с электронной почтой (шаблоны писем).

## Безопасность
*   Хеширование паролей (`bcryptjs`).
*   Валидация входных данных (`class-validator`).
*   Guard-мидлвары для проверки ролей и авторизации.
*   Защита от CORS.

## Скрипты запуска (из `package.json`)
*   `npm run dev`: Запуск в режиме разработки (с nodemon).
*   `npm run build`: Компиляция TypeScript.
*   `npm run start:production`: Запуск скомпилированной версии с предварительным пушем миграций БД.
*   `npm run test`: Запуск тестов.
*   `npm run generate:common` / `npm run generate:movies`: Генерация Prisma-клиентов.
